# CODSOFT - Artificial Intelligence Internship

This repository contains all the tasks completed during the CodSoft AI Internship.

---

## 🔹 Task 1 - Rule Based Chatbot

A simple chatbot developed using Python that responds to user input using predefined rules and conditional statements.

### Features:
- Greeting responses
- Tells date and time
- Basic conversation handling
- Exit option

Run using:
python chatbot.py

---

## 🔹 Task 2 - Tic Tac Toe AI

A Human vs Computer Tic Tac Toe game built using Python.

### Features:
- Player vs Computer
- Random AI move generation
- Win, Lose and Draw detection

Run using:
python tictactoe.py

---

## 🔹 Task 3 - Recommendation System

A simple movie recommendation system that suggests movies based on user selected genre.

### Features:
- Genre-based recommendations
- Rule-based decision logic

Run using:
python recommendation.py
